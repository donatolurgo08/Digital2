# Trabajo integrador

Espacio de trabajo del proyecto final de Electrónica Digital 2.

## Estructura

- `documentacion/`: consigna, contexto, especificaciones y notas.
- `src/`: código fuente.
- `simulacion/`: archivos y resultados de simulación.

La configuración de compilación queda pendiente hasta confirmar el microcontrolador,
el lenguaje y las herramientas requeridas por la consigna.

## Entorno disponible

- Windows y Visual Studio Code.
- MPLAB X 6.35 y XC8 4.00 (`pic-as`) instalados.
- El task existente en `.vscode/tasks.json` está configurado para PIC16F887;
  no asumir que ese es el dispositivo del proyecto final.
