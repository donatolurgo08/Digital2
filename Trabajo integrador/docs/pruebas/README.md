# Pruebas y validación

Registrar por separado los resultados de compilación, simulación y pruebas en
hardware real. No marcar una función como probada en hardware si solo se compiló
el firmware.

La validación integrada deberá cubrir adquisición del eje X, lectura de LM35 en
AN0, alarma para T > 40 °C, visualización multiplexada, comunicación bidireccional
con la GUI e interacción entre tareas. Los procedimientos concretos se agregarán
cuando estén definidos el circuito y los parámetros.
