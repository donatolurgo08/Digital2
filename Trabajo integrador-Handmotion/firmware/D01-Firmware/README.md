# D01-Firmware

Carpeta para el entregable D-01 de Donato Lurgo: investigación de periféricos
del PIC16F887.

- `D-01-investigacion-ADC.md`: investigación del ADC del PIC16F887.
- `D-01-investigacion-timers.md`: TIMER0, TIMER1 y TIMER2 del PIC16F887.
- `D-01-investigacion-EUSART.md`: investigación del EUSART del PIC16F887.
- `D-01-investigacion-GPIO.md`: GPIO, pines candidatos y cuidados eléctricos.
- `D-01-investigacion-interrupciones.md`: sistema de interrupciones del PIC16F887.

Los ejemplos serán de referencia y no reemplazan la implementación en
`firmware/src/`. Las configuraciones que dependan de datos aún pendientes se
documentarán como tales. La arquitectura del firmware (D-02) tendrá su propio
entregable.
